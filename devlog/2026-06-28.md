# 开发日志 — 2026-06-28

## ✅ 已完成

### Bug 修复：删除后仍提醒

**问题**：设置了提醒的任务删除后，到时间仍然弹出通知。

**根因**：`deleteHabit()` 只清除了存储数据，但没有取消已调度的通知。`TodayScreen.handleDelete` 虽然调用了 `cancelNotification()`，但属于外部调用，不够可靠。

**修复**：将 `cancelNotification()` 移入 `deleteHabit()` 内部，确保删除任何习惯时都自动取消通知，无论从哪个入口调用。

| 文件 | 变更 |
|------|------|
| `src/utils/storage.ts` | 导入 `cancelNotification`，在 `deleteHabit` 中调用 |
| `src/screens/TodayScreen.tsx` | 移除 `handleDelete` 中冗余的 `cancelNotification` 调用 |

### 新功能：日历补签

**需求**：在日历界面中，点击日期查看详情时，可以在"未完成"列表中对某个习惯进行补签。

**实现**：
- `src/utils/storage.ts`：`addCheckin(habitId, date?)` 新增可选 `date` 参数，未传则默认为今天（兼容原有调用）
- `src/screens/CalendarScreen.tsx`：
  - 提取 `loadDayDetail()` 函数，分离日期详情加载逻辑
  - 新增 `handleCatchUp(habitId)` 函数，调用 `addCheckin(habitId, dateStr)` 后刷新视图
  - "❌ 未完成"列表中每项右侧添加绿色"补签"按钮
  - 补签后自动刷新日历标记和详情列表

**联动**：
- `useTodayHabits.checkIn` -> `addCheckin(habitId)` — 不变，默认打今天
- `CalendarScreen.handleCatchUp` -> `addCheckin(habitId, dateStr)` — 新用法，打指定日期
