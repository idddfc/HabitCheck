# 产品需求文档 — HabitCheck

## 1. 产品概述

HabitCheck 是一款运行在 Android（小米澎湃OS/HyperOS）上的本地每日打卡 App，帮助用户追踪和管理日常习惯。

- **平台**: Android (HyperOS)
- **网络**: 纯本地，无需网络
- **版本**: V1.0

---

## 2. 功能列表

### 2.1 底部 Tab 导航

四个 Tab：今日 / 日历 / 统计 / 设置，点击切换。

---

### 2.2 今日 Tab

#### 2.2.1 环形进度条
- 顶部显示 SVG 环形进度
- 显示"已完成数 / 今日总数"
- 进度弧长度 = 已完成 / 总数 × 360°
- 全部完成时环形变完整

#### 2.2.2 任务列表
- 每条显示：emoji + 任务名 + 当前 streak + 打卡按钮
- 排序：未完成在上，已完成在下
- 打卡按钮点击后：
  - ✅ 图标替换
  - 缩放动画（spring, ~200ms）
  - 触觉震动反馈
  - 写入打卡记录

#### 2.2.3 空状态
- 无任务时显示："今天没有任务，去添加一个吧"
- 居中展示，配一个空盒子 emoji

---

### 2.3 添加任务

#### 2.3.1 触发方式
- 今日 Tab 右下角 FAB（浮动操作按钮）+ 号

#### 2.3.2 底部弹窗表单
| 字段 | 类型 | 说明 |
|------|------|------|
| 任务名 | TextInput | 必填，不为空 |
| Emoji | 选择器 | 预设 30+ 常用 emoji 网格，默认 📋 |
| 颜色 | 选择器 | 8 色圆形按钮，默认 #FF6B6B |
| 重复规则 | Chip 组 | 每日 / 工作日 / 自定义 |
| 自定义星期 | Chip 多选 | 仅在"自定义"时显示，日一二三四五六 |
| 提醒时间 | Switch + 时间选择 | 默认关闭，开启后选时间（HH:mm） |

#### 2.3.3 保存逻辑
- 校验后写入 AsyncStorage
- 如有提醒时间，调度本地通知
- 关闭弹窗，今日列表刷新

---

### 2.4 日历 Tab

- 月视图日历（react-native-calendars）
- 已完成日期打彩色圆点（颜色 = 对应 habit.color）
- 点击某天：底部弹出该日完成列表 + 遗漏列表
- 支持左右滑动切换月份
- 只读查看，不支持补打卡

---

### 2.5 统计 Tab

#### 2.5.1 每任务统计
- 当前连续天数（streak）
- 最长连续天数
- 本周完成率（条形图）

#### 2.5.2 全局鼓励文案
| 完成率 | 文案 |
|--------|------|
| ≥ 80% | 🎉 太棒了，继续保持！ |
| ≥ 50% | 💪 继续加油，你可以的！ |
| < 50% | 🌱 今天开始也不晚！ |

---

### 2.6 通知系统

- 本地通知，使用 expo-notifications
- 提醒内容："⏰ 别忘了打卡：[emoji] [任务名]"
- 任务创建/更新时调度通知
- 任务删除/归档/关闭提醒时取消通知
- 点击通知打开 App 并跳转到今日 Tab

---

### 2.7 删除与归档

- 长按任务卡片弹出菜单
- **归档**: 设置 archived=true，今日列表不显示，统计数据保留，通知取消
- **删除**: 二次确认后删除 habit + 关联 checkins + 取消通知
- 设置 Tab 可查看/恢复已归档任务

---

### 2.8 设置 Tab (V1)

- App 名称与版本号
- "已归档任务"入口
- "关于"信息

---

## 3. 用户故事

1. 作为用户，我希望能快速查看今天该做的任务并一键打卡
2. 作为用户，我希望创建任务时能灵活设置重复规则
3. 作为用户，我希望在日历上看到每月的打卡情况
4. 作为用户，我希望看到每个习惯的连续天数和完成率
5. 作为用户，我希望在设定的时间收到打卡提醒
6. 作为用户，我希望能够归档或删除不再需要的习惯
