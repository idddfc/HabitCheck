# UI 设计规范 — HabitCheck

## 1. 设计理念

**简洁、直观、温和** — 减少视觉噪音，让用户专注于打卡这一核心动作。

---

## 3. 字体

| 层级 | 大小 | 粗细 | 用途 |
|------|------|------|------|
| H1 | 24px | Bold(700) | 环形进度数字 |
| H2 | 20px | SemiBold(600) | 页面标题、日期 |
| Body | 16px | Regular(400) | 任务名、正文 |
| Caption | 14px | Regular(400) | streak、副文本 |
| Small | 12px | Regular(400) | 提示文字 |

---

## 4. 间距系统

| 名称 | 值 | 用途 |
|------|-----|------|
| xs | 4px | 标签内边距 |
| sm | 8px | 图标与文字间距 |
| md | 16px | 卡片内边距、元素间距 |
| lg | 24px | 区块间距 |
| xl | 32px | 页面边距 |

## 5. 圆角

| 名称 | 值 | 用途 |
|------|-----|------|

## 7. 组件规范

### 7.1 环形进度条
- 尺寸：160×160px
- 背景弧：`#E9ECEF`，宽度 12px
- 进度弧：`#6C63FF`，宽度 12px，圆角端点
- 中心文字：已完成数（H1 加粗）/ 总数（Caption 灰色）

### 7.2 任务卡片
- 高度：64px
- 背景：白色 `#FFFFFF`
- 圆角：12px
- 左侧 emoji（32px），中间任务名+streak，右侧打卡按钮
- 打卡按钮：直径 40px 圆形，边框 `#E9ECEF`
- 已完成态：按钮背景 `#4ECDC4`，白色 ✅

### 7.3 FAB 按钮
- 直径：56px
- 颜色：`#6C63FF`
- 图标：白色 + 号
- 位置：右下角，距边缘 24px
- 阴影：同卡片

### 7.4 底部弹窗
- 圆角：顶部 20px
- 背景：白色
- 最大高度：屏幕 80%
- 滑入动画：300ms ease-out

### 7.5 Emoji 选择器
- 3 列网格
- 每格 48×48px
- 选中态：背景 `#6C63FF20`，边框 `#6C63FF`

### 7.6 颜色选择器
- 8 个圆形按钮，直径 36px
- 间距 12px
- 选中态：外环 2px `#6C63FF`

### 7.7 Chip 按钮
- 高度：36px
- 圆角：18px（full）
- 未选中：背景 `#F1F3F5`，文字 `#6C757D`
- 选中：背景 `#6C63FF20`，文字+边框 `#6C63FF`

### 7.8 Tab Bar
- 高度：60px
- 背景：白色
- 选中图标/文字：`#6C63FF`
- 未选中：`#ADB5BD`
- 顶部 1px 分隔线 `#E9ECEF`
